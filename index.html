Netcup Backup

Netcup Backup — личное приложение для резервного копирования данных владельца сервера. Оно использует rclone для отправки зашифрованных архивов в закрытую папку владельца на Google Диске.

Зачем нужен доступ к Google Диску

Приложение загружает архивы и контрольные суммы, скачивает их для проверки и удаляет устаревшие копии из папки резервирования. Копии шифруются на сервере перед отправкой.
